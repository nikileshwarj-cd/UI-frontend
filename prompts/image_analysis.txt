## CRITICAL STRUCTURAL & LAYOUT ANALYSIS RULES
1. You MUST respond with ONLY a valid JSON object. No prose, no explanation, no markdown fences.
2. EXHAUSTIVE LAYOUT DIVISION: Analyze every visual section in the screenshot. Clearly identify and separate distinct structural containers:

   - Bottom Footer (`footer`)

4. Every UI element MUST receive a unique elementId following the pattern: UI_<TYPE>_<NNN> (e.g. UI_EMAIL_001, UI_SIDEBAR_LINK_001, UI_SUBMIT_BTN_001).
5. Element IDs must be UPPERCASE with underscores only.
